# Behavior retrieval and BCI

1. For tasks covered by the handbook, retrieve relevant behaviors first (`behaviors.getForTask` / CLI / MCP) so execution follows established patterns.
2. Declare **role** (Student / Teacher / Metacognitive Strategist) and cite **behavior + role** in plans and outcomes.
3. If no behavior fits after multiple attempts, escalate to **Metacognitive Strategist** pattern: solve, reflect, propose a behavior.
4. Deep reference: [AGENTS.md](https://github.com/SandRiseStudio/amprealize/blob/main/AGENTS.md) and BCI contracts in `docs/contracts/`.
